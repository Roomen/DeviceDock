    外观
    
                            
    跟随系统时按系统的浅色 / 深色自动切换；选中项立即生效并保存在本机。
    
                            
    
                                
    
                                    
    
                                        
    主题
    
                                        
    浅色 / 深色只影响界面，不改变设备行为。
    
                                    
    
                                    
    
                                        
                                        
                                        
                                    
    
                                
    
                            
    
                        
    

                        
    
                            
    参数与备份
    
                            
    导出的文件包含串口参数、协议、日志格式与快捷发送；导入与重置后页面会重新加载。
    
                            
    
                                
    
                                    
    
                                        
    导入配置
    
                                        
    从导出的 JSON 文件恢复参数，覆盖当前设置。
    
                                    
    
                                    
    
                                        
                                    
    
                                
    
                                
    
                                    
    
                                        
    导出配置
    
                                        
    把当前参数与快捷发送存成 devicedock-config.json。
    
                                    
    
                                    
    
                                        
                                    
    
                                
    
                                
    
                                    
    
                                        
    重置所有参数
    
                                        
    清掉串口参数、协议、日志格式与快捷发送，主题与日志内容不受影响。
