EXTENSIONS

扩展管理

安装只保存包；逐包信任该版本后才能启用。启用后每个带界面的插件拥有独立页面入口。

本地 JSON 包由集成工具生成；也可在设置的“插件与来源”中安装仓库版本。

信任记录

信任按「来源 + 包 ID + 版本 + 内容摘要」分别记录。新版本或不同来源必须重新授权；撤销信任会同时停用该包。参数导入不会恢复信任。

SETTINGS

设置

MCP 服务、应用更新、插件来源、参数预设与备份。

主题

主题立即生效并保存。命令面板中的切换与这里使用同一份设置。

界面密度

紧凑模式缩小行高与内边距，便于在双路分屏下同时观察日志。

参数预设

单路 / 双路预设保存串口参数、协议与路标签，不包含设备授权。

参数导入与备份

只包含界面、路参数、日志显示与快捷指令。信任决定、已启用包、发送历史和设备别名不在备份范围内。

仓库来源

来源只提供目录，不会在添加后执行任何代码。离线时保留最近验证的目录。

客户端服务

原生 MCP 与应用更新仅在桌面客户端提供。
