# Early review disposition

Source: coordinator `/tmp/devicedock-early-review.md` (read-only review). Actual implementation was checked, then targeted regressions added in `tests/host.test.mjs`.

1. Package-relative escape: resolve inside an explicit package-root prefix and reject escape. Producers now package complete internal graphs. Regression tests reject root `../` imports.
2. Owner-scoped drain: tracked transaction and write promises carry owner identity; disable calls drainOwner only for itself. Regression disables an observer while another extension transaction continues.
3. Close/claims/generation: closing and closed records notify subscriptions; claims clear only after actual physical release. Claim epochs prevent late old disposers from releasing new claims. Power worker handles its local capture state on generation change.
4. Activation race: disable refuses enabling state; activation finalizer remains tracked. Regression covers awaited activate.
5. Hung I/O: close requests writer.abort and exposes cleanup-needed after bounded wait; actual operation retains port and claim until it settles. Regression uses deliberately hung driver and proves another lane remains blocked.
6. Final cleanup I/O: only the awaited finalizer is allowed owner-scoped writes/transactions while stopping. New public work remains rejected; owner claim persists until finalizer completes. Regression proves final device write reaches real stream.
7. Resource selection: host.resources.requestPort(providerId, options) uses registered transport, available to dedicated sessions. `org.devicedock.serial.v1` also exposes the serial provider. No device I/O occurs on selection.
8. Native capabilities: shell reports compiled capabilities through host_capabilities; JS checks it rather than assuming Tauri implies serial. Native mobile serial is not advertised.
9. Source collisions: simultaneous same-manifest-id activation is rejected; UI selects an explicit source/version; storage and owner identity include source. Failed version switch restores prior activation; old verified artifacts remain available. Canonical services reject duplicate registration and are owned/reclaimed by their registering extension. Trusted same-realm code cannot be security-sandboxed by a registry.
10. Extension diagnostics: bounded host diagnostics are separate from lane RX/TX records.
11. Service worker: cached-module enable requires a controller; already-complete same-hash caches are reused without rewriting/deleting. Install jobs serialize and completion marker is written last.

Additional: preflight rejection leaves extension enabled/unaborted; actual native adapter/stream modules and regression suites ported rather than weaker placeholder; native release_owned fences document initialization and pagehide. Source configuration/catalog validation tests cover duplicates, unsupported URL forms, corrupt cache and offline refresh preservation.

Native follow-up: desktop now supports runtime source/local install, not just CLI repackaging. Native SHA-256 validation, atomic cache, no-symlink containment, read-time byte checks and JS canonical-vector regression are in desktop/src-tauri/src/extensions.rs. Correct ESM/WASM MIME and CORS, CSP wasm-unsafe-eval/blob worker policy, and host.assets read/createWorker bridge handle non-ESM resources. Worker source is verified and self-contained; WASM bytes travel from the verified main-thread read to worker by message. The native-smoke build feature is test-only and absent from ordinary builds.

Further host hardening: contribution disposers are idempotent and cannot remove later owners; active transport extensions cannot unload while host sessions use their ports; update preflights all extensions before teardown and freezes raw/new work; parsers are newly instantiated per connection/replay generation; decoded frame data remains on logs; source/version compatibility and complete directory parity are rechecked during integration. Generated packages are ignored and the source repo remains zero-plugin launchable.
